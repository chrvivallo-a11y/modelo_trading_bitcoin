# Trading Bot Cuantitativo - Notbank

Infraestructura de datos y ejecución algorítmica para el exchange Notbank. 

## Estructura
* `src/recolector_notbank.py`: Se conecta a los WebSockets para obtener tick data (Level 2 y Trades) del mercado spot.
* `src/recolector_derivados.py`: Obtiene datos de apalancamiento global (Open Interest y Funding Rates).
* `src/agregacion_15m.py`: Transforma los CSVs crudos en velas de 15 minutos con indicadores matemáticos y desbalance del libro.
* `src/notbank_trading.py`: Funciones para ejecutar órdenes de compra y venta.

## Uso
1. Crear entorno virtual: `python -m venv venv`
2. Activar entorno virtual y ejecutar: `pip install -r requirements.txt`
3. Copiar `.env.example` a `.env` y agregar las llaves API.
4. Ejecutar recolectores dentro de `src/` para poblar la carpeta `/data`.
